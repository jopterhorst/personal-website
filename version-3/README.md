# Version 03 — After Hours

A separate, quieter personal site at `/version-3/`. Versions 01 and 02 remain unchanged.

Deep indigo, lavender, pale yellow, expressive serif typography, a portrait orbit, and collected objects give this version a personal night-journal feel. Copy is intentionally shorter and less promotional, focused on automation and practical problem solving at work and at church. The five public projects, corrected current role, connected Siemens history, and existing portrait are retained. Older jobs use native disclosures. No build step or runtime dependency; Google Fonts have system fallbacks, and all content and controls work without JavaScript.

The footer links to both other versions. The comparison page is marked `noindex,follow`; no hosting configuration is changed and nothing is deployed.
