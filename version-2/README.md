# Version 02 — The Workbench

An independent alternative to the original Liquid Glass portfolio. The original homepage, CSS, JavaScript and documentation are unchanged.

Open `/version-2/` on the existing local preview server. The masthead and footer link back to Version 01 at `/`.

The design uses warm paper colors, large Barlow Condensed headings, Space Grotesk body text, IBM Plex Mono annotations, square layouts, an editorial career ledger and original CSS illustrations. Project filters and a separate theme preference work in vanilla JavaScript. All content remains visible when JavaScript is unavailable. Theme storage uses `portfolio-v2-theme`, so it does not change Version 01’s preference.

Career information, public projects and product positioning come from the current approved homepage. The corrected title, connected Siemens roles, removed promotion badge and DPP removal are preserved. The current portrait is reused from `../assets/profile-photo.png`.

This comparison version is marked `noindex` until a preferred design is chosen. There is no build step or new runtime dependency; fonts load from Google Fonts with system fallbacks. The existing static hosting configuration remains unchanged.
