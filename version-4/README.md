# Version 04 — Jop OS

A separate comparison at `/version-4/`. All three earlier versions remain intact.

A bright, playful personal desktop: pixel typography, pastel title bars, file icons, chunky borders, and movable windows. Content stays brief and focuses on automation and practical business problems, including at church. The five public projects, current portrait, exact current job title and connected Siemens history are retained.

On desktop, drag a window using its dotted handle or focus the handle and use arrow keys. Home restores that window; Tidy desktop restores all windows. Resizing also resets the layout. On mobile, windows become a linear reading order and movement controls disappear. Native career disclosures and all links work without JavaScript. No pretend app controls, build step, storage, or runtime dependencies. Google Fonts have local system fallbacks.

The top menu links to all three other designs. Marked `noindex,follow` for comparison. Hosting configuration is unchanged; nothing is deployed.
